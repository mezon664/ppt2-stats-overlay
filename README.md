# PPTetrics

> 非公式のファンツールです。セガ（ぷよぷよテトリス2）・The Tetris Company とは関係ありません。
> 作者: めぞん、Claude（Anthropic の AI）

ぷよぷよテトリス2（PC版）のテトリスの対戦画面に、APM・PPS・APP などの数値、イベント履歴、開幕テンプレ名、試合結果を重ねて表示するツールです。
ゲームの画面を見て読み取るだけで、ゲームのメモリや入力には一切触れません。

## できること

- APM / PPS / APP / 送った段数 / 置いたミノ数 / REN / Back-to-Back を、ゲームの上と OBS に表示
- T-SPIN（シングル・ダブル・トリプル・Mini・ライン消去なし）、TETRIS、パーフェクトクリア、REN、Back-to-Back の履歴
- 開幕テンプレ名の表示（テトリステンプレ整理Wiki の約1450種類。お邪魔を受けていても判定）。猫が紙で見せてくれる表示もあります
- 試合が終わったときの結果まとめ
- デザイン13種類、色・フォント・文字の太さ・大きさ・位置（1P と 2P を別々にも）を自由に変更、プリセット保存
- 試合画面のときだけ表示（常に表示も可）、1P だけ／2P だけの表示、ぷよを使っている側は自動で非表示
- 日本語版・英語版のゲームに対応、表示の言語も日本語／English
- アップデート通知とボタン1つでの更新

## 動かし方

1. リリースページ（https://github.com/mezon664/ppt2-stats-overlay/releases ）から **PPTetrics-full-v○.○.○.zip** をダウンロードします（Python は不要です）。
2. 好きな場所に展開して、`start.bat` をダブルクリックすると起動します。ゲームの上に数値が表示されます。
3. 設定は、画面右下の通知領域（「^」を押すと出るアイコンの中）の PPTetrics のアイコンから開けます。

- 初めて起動するとき、Windows の「PC が保護されました」という画面が出ることがあります。「詳細情報」→「実行」で起動できます（署名のない個人製作のツールのためです）。
- ゲームはウィンドウ表示にしてください（フルスクリーンでは読み取れません）。
- ゲームの画面の上にほかのウィンドウを重ねないでください（重なった部分は読み取れず、試合の開始などを見落とします）。

自分の Python（3.12）で動かす場合は、このフォルダで次を1回実行してから `start.bat` を使います。

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## OBS に映す

設定画面の「OBSに映す」タブの手順どおりに、`obs/overlay.html` をブラウザソースとして追加します。

## アップデート

起動したときに新しい版があると、右下に通知が出ます。設定画面の「アップデート」タブの「更新して再起動」で更新できます。
設定・読み込んだフォント・プリセットはそのまま残ります。勝手に更新されることはありません。
