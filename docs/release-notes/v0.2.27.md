# v0.2.27

- 連戦の平均を出せるようにしました。
  - 試合結果の APM・PPS・APP・VS SCORE の下に、その連戦の平均を小さく出します。タイトルの下には「連戦 3試合の平均（2-1）」のように試合数と勝敗が出ます。設定画面の試合結果の欄にある「連戦の平均も出す」で切り替えます（初期設定はオフ、連戦の2試合目から出ます）。
  - 連戦の区切りは、画面下の WIN の星を読んで決めます。0-0 の試合から数え直します（星の表示と「0★ WIN ★0」の数字の表示の両方に対応）。星が読めないときは、前の試合から10分以上空いたら数え直します。「連戦の平均をリセット」ボタンで手動でも数え直せます。
  - 設定画面の「試合の統計」に「連戦ごとの平均」を追加しました。連戦ごとに日時・試合数・勝敗と、APM・PPS・APP・VS SCORE の平均（1P / 2P）を並べます。この版から遊んだ試合が対象です。
- テンプレ名などの表示が、まれに一瞬で消えることがあったのを直しました（開発用の画像保存をオンにしているときだけ起きていました）。
