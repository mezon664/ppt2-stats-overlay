# v0.2.25

- 新しいデザイン「中継」と「スポーツ斜体」を追加しました。どちらも専用のフォント（中継は Barlow Condensed、スポーツ斜体は Saira Condensed）で表示します。
- 「見た目」→「文字」に「斜体」を追加しました。オンにすると、どのデザインでも文字が斜めになります。
- フォントの初期設定がデザインごとになりました（中継・スポーツ斜体は専用のフォント、それ以外はメイリオ）。フォントの一覧の一番上に「〇〇（初期設定）」と出ます。ほかのフォントを選ぶと、どのデザインでもそのフォントになります。
- 設定画面の「見本」に、ゲーム画面全体にどう表示されるかの全体図を足しました。上の見本も、ゲームの上の表示と同じ項目・並びで出るようにしました。
- 開幕テンプレの認識を直しました。
  - 合掌TSD の T スピンのあと、名前が「婿TD」に書き換わることがあったのを直しました。一度出た名前は、それより小さい形では書き換えません。
  - 組んでいる途中の形で、別のテンプレの名前（婿TD など）が出にくくなりました。
  - T スピンダブルで段を消すテンプレで、実際には使わない T の入れ方（壁際で上向きなど）を候補から外し、関係ない積みに名前が付きにくくしました。
  - パフェ積みを組むと一瞬「パフェ積み / 新MT砲」と出ていたのを直しました。ホールドのミノを置く場所でテンプレが変わるときは、置かれるまで待ちます。
