# v0.2.14

- 試合結果の開幕テンプレ名が長いとき、途中で切らずに最大 3 行まで折り返して表示するようにしました（HUD・OBS とも）。
- 縛りプレイを追加しました（「表示する項目」の一番下）。自分の盤面に、ゲームを難しくする表示を出します。ゲーム画面だけで、OBS（配信）や認識には映りません。
  - NEXT を隠す：2個目から、または全部を隠します。
  - 猫：TETRIS・T-SPIN・パフェクリのたびに猫が 1 匹ずつ増えて、盤面の上を歩き回ります（試合が終わるといなくなります）。
  - ゲーム画面の上の表示が認識に写り込むパソコンでは、認識が壊れるので使えません（設定画面にそう出ます）。
