- 縛りプレイを追加しました（「表示する項目」の一番下）。自分の盤面に、ゲームを難しくする表示を出します。ゲーム画面と OBS（配信）に出て、認識には映りません。
  - NEXT を隠す：2個目から、または全部を隠します。
  - 猫：TETRIS・T-SPIN・パフェクリのたびに、画面の端から実写の猫が出てきて盤面を隠します。
  - ゲーム画面の上の表示が認識に写り込むパソコンでは、認識が壊れるのでゲーム画面には出しません（OBS には出ます。設定画面にそう出ます）。
