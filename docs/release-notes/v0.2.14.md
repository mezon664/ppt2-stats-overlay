# v0.2.14

- 縛りプレイを追加しました（設定画面の「縛りプレイ」）。自分の盤面の NEXT を隠して、見える NEXT の数を 5〜0 個から選べます。ゲーム画面と OBS（配信）に出て、認識には映りません。
  - 対象の盤面は、自分（自動）・1P・2P から選べます。
  - ゲーム画面の上の表示が認識に写り込むパソコンでは、認識が壊れるのでゲーム画面には出しません（OBS には出ます。設定画面にそう出ます）。
- 数値の置き場所（盤面の左下／右下）を、1P と 2P で別々に選べるようにしました（「位置」の画面）。ゲーム画面と OBS の両方に効きます。
- 設定画面がゲームに重なっていないときは、普通のスクショ（PrintScreen など）に写るようにしました。ゲームに重なっているあいだは、認識を守るため今までどおり写りません。
- 設定画面の下に「画像で保存」ボタンを付けました。今の設定画面（レートの推移など）を「ピクチャ」の PPTetrics フォルダに保存し、クリップボードにもコピーします。
- 試合結果の開幕テンプレ名が長いとき、途中で切らずに最大 3 行まで折り返して表示するようにしました（HUD・OBS とも）。
