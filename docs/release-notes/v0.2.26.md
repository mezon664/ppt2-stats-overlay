# v0.2.26

- 新しい数値「VS SCORE」を追加しました。［攻撃量＋消したおじゃまのライン数］÷ 秒数 × 100 で、攻めと掘りの両方を合わせた強さの目安です。設定画面の「表示する項目」で選べます。試合結果にも出せます（初期設定はオフ）。
- 読み取りを軽くしました。1コマあたりの処理時間が約半分、CPU の使用量も約半分（約47%減）になりました。
- 試合結果の読み取りを直しました。
  - T-SPIN が続けて出たとき、2回目以降を数え損ねることがあったのを直しました。
  - REN で決着したとき、最大REN が1少なくなることがあったのを直しました。
  - 試合が終わったら、試合結果がすぐ出るようになりました（最後の消去を数え終わるのを待つときだけ少し遅れます）。
- 「ゲームの読み取り元」に「ウィンドウ」を追加しました。キャプチャーボードの映像を、配信ソフトのプロジェクターから読めます（仮想カメラは要りません）。
- 開幕テンプレの認識を直しました。
  - ホールドしているミノの置き場所を推測して名前を出すのをやめ、置かれてから出すようにしました（はちみつ砲が山岳積み2号や上弦積みと出るなど）。
  - 途中まで同じ形のテンプレ（山岳積みと山岳積み2号、ガムシロ積みと婿TD など）は、見分けのつくミノが置かれるまで待つようにしました。
  - 次の巡のミノが混ざった盤面を、別のテンプレと取り違えないようにしました。
  - テンプレ名の先頭の顔文字が消えて「パフェ」のように出ていたのを直しました。
- 起動できないとき、原因をメッセージで出すようにしました。
- 設定画面の数値の説明をわかりやすくしました。設定画面の色の切り替えはなくしました。
