名前が **PPTetrics** になりました。Python を入れなくても動く版（PPTetrics-full）も用意しています。

### 新しくできること
- 開幕テンプレの判定を、テトリステンプレ整理Wiki のテンプレ一覧の全テンプレ（約1450種類）に広げました
  - 1巡目で T-SPIN をする開幕は、T を入れる直前の形で判定します
  - 同じ形の開幕が複数あるときは、名前を2つまで表示します（それ以上は「ほか」）
- 開幕テンプレ名の新しい出し方「E 猫」：猫が画面の外から歩いてきて、テンプレ名を書いた紙を見せてくれます
- 英語版のぷよぷよテトリス2に対応しました（「Yeah!」での試合終了、ポーズ画面など）
- 表示の言語が English のとき、開幕テンプレ名を英語名で表示します（Hard Drop の名前。英語名がないものは日本語）。テンプレ名の言語は設定で個別に選べます
- 表示のオン／オフを、設定画面のいちばん上と、通知領域のアイコンから切り替えられます。ホーム画面などで隠れているときも、ボタンで表示できます
- 位置の調整
  - 数値・テンプレ名を 1P と 2P で別々に動かせます（両方一緒にも動かせます）
  - ゲーム画面上でドラッグするとき、マウスホイールで大きさも変えられます
- 新しいアイコン

### 直したこと
- 相手がぷよのとき、ポーズしても数値が止まらないことがある問題（英語版）
- 相手がぷよのとき、数値が盤面の枠にかぶって右にずれて見える問題
- 試合時間・試合結果がわずかに右に寄っていた問題
- アプリを2つ起動すると表示が二重になる問題（2つ目は設定画面を開くだけになりました）

### 更新するとき
- v0.1.0 からは、設定画面の「アップデート」タブの「更新して再起動」で更新できます。設定はそのまま残ります。
- はじめて使う方は **PPTetrics-full-v0.2.0.zip** をダウンロードしてください（Python は不要です）。
