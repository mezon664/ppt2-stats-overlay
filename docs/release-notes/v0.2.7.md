# v0.2.7

- 試合結果の「T-SPIN」に、ラインを消さない T-SPIN と T-SPIN Mini も数えるようにしました（イベント履歴には出ているのに、試合結果では 0 になることがありました）。
- 試合結果がほかの表示（数値・イベント履歴・試合時間など）と重なったとき、試合結果を上に表示するようにしました。
- ゲーム画面の上の表示（HUD）が、起動直後にほかのウインドウ（Discord など）の上に出てしまうことがあったのを直しました。ゲームのウインドウの上に置けるまでは何も表示しません。
- モニターが 2 台以上ある場合や、拡大率（125%・150% など）が 100% でないモニターで、HUD の位置がずれたり見えなくなったりすることがあったのを直しました。
- HUD が OBS には出ているのに画面に出なくなる、という報告に備えて、HUD がゲームの後ろに隠れたときは前に戻すようにしました。HUD の状態を `logs` フォルダ（hud_status.txt / hud.log）に記録します。うまく表示されないときは、通知領域のメニュー「うまく認識しないとき：診断ファイルを開く」の中身を送ってください。
