# v0.2.11

- 「今日の成績」を追加しました。ぷよテト2を起動してからの勝敗と勝率、連勝数、レートの増減、平均 APM / PPS / APP を、設定画面の「試合の統計」で見られます（ゲームを閉じるとリセット、このアプリを再起動しても続きから数えます）。
- 「今日の成績」は、ゲーム画面の上や OBS にも出せます（盤面のあいだの上）。設定の「表示する項目」→「今日の成績」でオンにできます（初期はオフ）。「位置」で動かせます。
- T-SPIN が数えられないことがあったのを、いくつかの原因について直しました。
  - ゲーム画面の上の表示（HUD）が、パソコンによっては認識が読む画面に写り込み、T-SPIN の表示を隠していました。写り込むパソコンでは、ゲームのウィンドウそのものから読むようにしました。
  - ゲームのウィンドウが 16:9 から少しずれていて、ゲームの絵の周りに黒い帯があると、読み取る位置と表示の位置がずれていました。黒い帯を取り除いて、ゲームの絵だけを読むようにしました（表示もゲームの絵に合わせます）。
  - 画面が白っぽく写るパソコン（Windows の HDR など）で、ほとんど認識できないことがあったのを直しました。
  - 色が薄く写るパソコンで、T ミノを読めずに PPS や T-SPIN が数えられないことがあったのを直しました。
- うまく認識しないときの診断ファイルに、表示が写り込んでいないかと、どこから画面を読んでいるかを記録するようにしました。
