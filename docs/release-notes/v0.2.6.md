# v0.2.6

- 認識を軽くしました。ゲームのウィンドウが大きいときは、基準の大きさに縮めてから読み取ります（約2倍速く）。大きなウィンドウや低スペックのPCで、T-SPIN や消去を見逃したり、REN の数がずれたり、試合開始が遅れて開幕テンプレを認識しなかったりするのを減らします。
- 開幕テンプレ名の表示（特に「猫」）を軽くしました。大きいウィンドウでもなめらかに動きます。
- 開幕テンプレの表示を「猫」に切り替えた最初の1回、アプリが一瞬止まって表示がちらつくのを直しました。
- 画面が暗転したときに数値と試合結果を消す動きを、元の仕様に戻しました（v0.2.2〜v0.2.5 では試合結果が消えずに残っていました）。暗転を見落としにくくもしました。
- 対戦のセット終了時、勝ったキャラクターのセリフが出たときに 1P（または 2P）の数値が消えてしまう問題を直しました。
- 認識がうまくいかないときのために、アプリに見えている画面と認識の状態を `logs` フォルダに保存するようにしました。通知領域のメニュー「うまく認識しないとき：診断ファイルを開く」から開けます。
- 開発用の環境（`.venv`）から起動すると、アプリが立ち上がらない問題を直しました。
- アプリが正常に終了しなかったとき、`pythonw.exe`（認識プログラム）が残り続けることがあったのを直しました。アプリが終わると、認識プログラムも自動で終わります。
- OBS に映す表示を、ゲーム画面の上の表示（HUD）と同じ見た目にしました。配置・大きさ・文字の位置が HUD と一致します（違うのは文字のふちのぼかし方くらいです）。OBS 側のブラウザソースはそのままで、自動で新しい表示に切り替わります。
- ぷよぷよのプレイヤーとの対戦中は、試合時間を表示しないようにしました（マージンタイムがどこまで進んだか分かると、片方が有利になってしまうため）。「試合中断中」などの表示は今までどおり出ます。
- アプリを軽くしました。
  - 試合中の認識の CPU 使用量を約 4 割減らしました。
  - ホーム画面やメニューにいるあいだは、ゲーム画面を読み取る回数を減らします（CPU 使用量が約半分以下に）。
  - 「猫」の表示で使うメモリを約 3 分の 1 にしました（ゲーム画面の幅 1756 で 約 380MB → 約 130MB）。ほかの表示に切り替えると、そのメモリは手放します。
  - 画面の表示に変化がないときは、描き直しをしないようにしました。
