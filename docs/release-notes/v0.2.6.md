# v0.2.6

- 認識を軽くしました。ゲームのウィンドウが大きいときは、基準の大きさに縮めてから読み取ります（約2倍速く）。大きなウィンドウや低スペックのPCで、T-SPIN や消去を見逃したり、REN の数がずれたり、試合開始が遅れて開幕テンプレを認識しなかったりするのを減らします。
- 開幕テンプレ名の表示（特に「猫」）を軽くしました。大きいウィンドウでもなめらかに動きます。
- 開幕テンプレの表示を「猫」に切り替えた最初の1回、アプリが一瞬止まって表示がちらつくのを直しました。
- 画面が暗転したときに数値と試合結果を消す動きを、元の仕様に戻しました（v0.2.2〜v0.2.5 では試合結果が消えずに残っていました）。暗転を見落としにくくもしました。
- 対戦のセット終了時、勝ったキャラクターのセリフが出たときに 1P（または 2P）の数値が消えてしまう問題を直しました。
- 認識がうまくいかないときのために、アプリに見えている画面と認識の状態を `logs` フォルダに保存するようにしました。通知領域のメニュー「うまく認識しないとき：診断ファイルを開く」から開けます。
- 開発用の環境（`.venv`）から起動すると、アプリが立ち上がらない問題を直しました。
- アプリが正常に終了しなかったとき、`pythonw.exe`（認識プログラム）が残り続けることがあったのを直しました。アプリが終わると、認識プログラムも自動で終わります。
- OBS に映す表示を、ゲーム画面の上の表示（HUD）と同じ見た目にしました。配置・大きさ・文字の位置が HUD と一致します（違うのは文字のふちのぼかし方くらいです）。OBS 側のブラウザソースはそのままで、自動で新しい表示に切り替わります。
- ぷよぷよのプレイヤーとの対戦中は、試合時間を表示しないようにしました（マージンタイムがどこまで進んだか分かると、片方が有利になってしまうため）。「試合中断中」などの表示は今までどおり出ます。
- ゲーム画面の上の表示と OBS の表示を、それぞれオン・オフできるようにしました。設定画面の上の「ゲーム画面に表示」「OBS に表示」、または通知領域のメニューから切り替えられます（たとえば配信の画面にだけ出して、自分の画面には出さない、など）。
- 設定画面に「試合の統計」タブを追加しました。直近の何試合かの平均 APM・PPS・APP・送った段数・置いたミノ・最大REN と、開幕テンプレごとの使用率（円グラフ）・勝率を見られます。試合が終わるたびに自動で更新されます。1P・2P、対テトリス・対ぷよぷよ・すべてを切り替えられ、何試合分を集計するか（10〜500 試合）もボタンで選べます。勝敗がついた試合だけを数え、記録は直近 500 試合まで残ります。
- 設定画面を作り直しました。左のメニューから「ホーム」「表示する項目」「見た目」「位置」「試合の統計」「OBS に映す」「その他」を選びます。表示する部分ごとにカードにまとめ、オフにした部分の細かい設定は隠れるようにしました。
- 設定画面を少し小さくしました。各項目の右上に「元に戻す」ボタンを付けました（その項目だけ初期設定に戻します。変えていない項目では押せません）。
- 設定画面の色をモノクロ（黒・白・灰色）にしました。「その他」→「設定画面の色」で、紺・ライト・ゲーム風にも変えられます。
- 「ぷよテト2と一緒に起動」を追加しました（設定のホーム）。オンにすると、ゲームを起動したときにこのツールも自動で起動します。
- 文字の縁の太さを変えられるようにしました（設定の「見た目」）。
- OBS で、半透明の背景が HUD より薄く見えていたのを直しました（OBS は色を重ねる計算の仕方が違うため、それに合わせました）。
- オンライン対戦のレートの推移を見られるようにしました（設定の「レートの推移」）。対戦前の「まちうけ」画面とリーグのメニュー画面から、自分のレートを自動で読み取って記録し、グラフで表示します。パズルリーグ・テトリスリーグ・ぷよぷよリーグ・スキルバトルリーグを分けて見られます。
- 開幕テンプレを組んでいる途中で、関係ない別のテンプレ名が出ることがあったのを減らしました（7 ミノそろう前の形は、もう 2 ミノ置くまで待ってから出します）。
- 英語版のゲームで、試合開始の「START!」を見逃して試合の始まりが遅れ、最初の数秒の T-SPIN Double などが数えられないことがあったのを直しました。
- ゲームのウィンドウ（ボーダーレス）フルスクリーンに対応しました。ふつうのフルスクリーンは今までどおり読み取れません。
- アプリを軽くしました。
  - 試合中の認識の CPU 使用量を約 4 割減らしました。
  - ホーム画面やメニューにいるあいだは、ゲーム画面を読み取る回数を減らします（CPU 使用量が約半分以下に）。
  - 「猫」の表示で使うメモリを約 3 分の 1 にしました（ゲーム画面の幅 1756 で 約 380MB → 約 130MB）。ほかの表示に切り替えると、そのメモリは手放します。
  - 画面の表示に変化がないときは、描き直しをしないようにしました。
- v0.2.4 以前をお使いの方へ: 設定画面の「今すぐ確認」で「確認できませんでした」と出ることがありました（GitHub の問い合わせ回数の上限のため。v0.2.5 で直っています）。その場合は、GitHub のリリースページから一度だけ手動でダウンロードしてください。v0.2.5 以降は設定画面から更新できます。
