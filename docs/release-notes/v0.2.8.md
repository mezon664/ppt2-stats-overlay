# v0.2.8

- 置くのが速い人の PPS が 0.1 などになり、ほとんど動かないことがあったのを直しました。パソコンの処理が追いつかず、ゲーム画面を読み取る回数が少ないときに起きていました（NEXT の並びが読み取りのたびに変わり、置いた数を数えられていませんでした）。読み取りが少なくても数えられるようにしました。
- 認識を軽くしました。試合中の 1 コマあたりの処理が約半分になります（消去のバナーは消去の光が出たあとだけ探す、試合が終わったあとは「やった!」を探さない）。パソコンが重いときでも読み取りの回数が増え、PPS・T-SPIN・REN の数えそこねが減ります。
- 長い試合でメモリが少しずつ増えていたのを直しました。
