# v0.2.12

- 一部のパソコンで T-SPIN が数えられなかったのを直しました。原因は、ゲーム画面の上の表示が、アプリの読み取りにも写り込んでいたことです（Windows 10 の古いバージョン（2004 より前）などで起きます）。数値やイベント履歴が、盤面の左下に出る「T-SPIN」のバナーを隠していました。
  - そのパソコンでは、盤面の左下・右下に出る「T-SPIN」などのバナーや、盤面・NEXT・HOLD に重なる表示を、ゲーム画面には出さないようにしました。OBS には今までどおり出ます。
  - 設定画面のホームに、そのことと、どの表示を隠しているかが出ます。「位置」で盤面とバナーから離れた場所に動かすと、ゲーム画面にも出ます。
