# 開幕テンプレ全部対応の進捗（作業の続きはここから）

ユーザーの依頼（2026-10-31）: テトリステンプレ整理Wiki（https://w.atwiki.jp/sasasa123/）の開幕テンプレを全部判定できるようにする。
セッション制限で止まっても、このファイルを見て続きから再開する。

## やり方
- Wiki は Cloudflare で curl 不可 → 内蔵ブラウザで開き、ページ内の `fetch()` で取得する。
- 各ページの「タグ」に開幕の形（テト譜 v115@...、灰色ブロック）が付いている。タグ一覧 `/tag/?p=N` → 各タグ `/tag/<テト譜>` で付いているページを集める。
- 集めた結果は `tools/opener_import/wiki_tags.json`（タグ→ページ）に保存。
- 形が開幕テンプレ（1巡目の形）か、ほかのもの（2巡目・派生など）かは、ページのタイトルと形の大きさで仕分ける。
- `assets/openers.json` に追加 → `tests/test_opener.py`（形がほかの開幕と重ならないか）→ 全録画で誤検知がないか（`opener_scan` と同じやり方）。

## 分かったこと
- 「テンプレ一覧」https://w.atwiki.jp/sasasa123/pages/1851.html に全テンプレが分類（見出し）つきで載っている: 1471ページ。
- 各ページの形タグは `#atwiki-page-tags` の中だけ。サイドバーにも毎回ちがうタグが出るので、ページ全体から拾うと混ざる（1回目はそれで失敗）。
- 内蔵ブラウザで 1 呼び出し 45 秒まで → ページ内で裏で回す。結果は atwiki 側の localStorage `opener_import` に保存（再読み込みでも残る）。
- ブラウザから PC への受け渡し: window.name（サイトをまたぐと消える）・localhost への送信（ブロックされる）は不可 → 圧縮して数回に分けて取り出し、`tools/opener_import/wiki_tags.json` に書く。
